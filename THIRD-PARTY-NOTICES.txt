CyHWInfo third-party notices
==========================

The optional LibreHardwareMonitor module ships its separate notices, license
texts and corresponding source links in the cyhwinfo-lhm/licenses directory.
See src/lhm_bridge/licenses/SOURCES.txt in the source distribution.

The optional Windows application ships CyUI, Dear ImGui and JetBrains Mono
notices beside the executable in the licenses directory. UI integrations use
the host's compatible CyUI and Dear ImGui targets.

lfreist/hwinfo
Commit 1a77a8088919b98b417ab3ffd0ac5d0eb3a6ba96
https://github.com/lfreist/hwinfo
Linked as independent static components. Its PCI ID data uses the BSD-3-Clause option below.

gputaskman
Commit 27e3ab96464837d44a3db2952d05335e6d7f9db0
https://github.com/shanselman/gputaskman/blob/27e3ab96464837d44a3db2952d05335e6d7f9db0/src/gputaskman/pdh.py
The WDDM performance counter collection and adapter matching were adapted to C++.

CrystalDiskInfo
Commit cabe686f0b09a8d0a777a24b410c0041630010ad
https://github.com/hiyohiyo/CrystalDiskInfo/blob/cabe686f0b09a8d0a777a24b410c0041630010ad/AtaSmart.cpp
The NVMe health log and ATA SMART queries were adapted to C++ using Windows SDK types.

windows_exporter
Commit 8ff62232a06a3f28f3bbbf8a3091d2a76f89f04c
https://github.com/prometheus-community/windows_exporter/blob/8ff62232a06a3f28f3bbbf8a3091d2a76f89f04c/internal/collector/gpu/sensors.go
The WDDM physical adapter and engine sensors were adapted to C++.
